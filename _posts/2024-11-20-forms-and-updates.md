# 2025 Required Forms & Tournament Updates

Hello GGSO community, 

We hope you are all doing well and getting excited for Thanksgiving break! As we get closer to the tournament, we would like to give some friendly reminders and updates. 

**Forms**
<br/>
Every minor attending the 2025 tournament (including alternates, spectators, etc.) must fill out **four forms**: 
1. First is the general **student release form** which can be found in <a target="_blank" href="https://scilympiad.com/golden-gate/">Scilympiad</a>.
2. Second is a **liability waiver** that can be found <a target="_blank" href="https://drive.google.com/file/d/1nMRgTdc3Gz2bLlU9qDMh3EJq4tggfiHu/view?usp=sharing">here</a>.
3. Third is a **photo release form** that can be found <a target="_blank" href="https://drive.google.com/file/d/1fY3WunjC_NpDHAFpKyQMLdm06lulQpWq/view?usp=sharing">here</a>.
4. Fourth is a **consent to treatment of minor form** that can be found <a target="_blank" href="https://drive.google.com/file/d/17t_3RGw8CGYCMnuZ7N8ytSlVJB46c-SF/view?usp=sharing">here</a>.

The general student release form should be submitted through **<a target="_blank" href="https://scilympiad.com/golden-gate/">Scilympiad</a>**. The liability waiver, photo release form, and consent to treatment form should be submitted through **<a target="_blank" href="https://forms.gle/i9A2dnpGcAXV6EVH7">this Google Form</a>**. **All four forms are due by January 17th, 2025**. Please note that we will destroy submitted documents right after the tournament, in case there is any concern about the information we are gathering. 

**Additional Updates**
<br/>
The **event list** for the tournament can be found <a target="_blank" href="https://docs.google.com/document/d/14R6yeOpYuJOrominZA5FuteTundIvwJKvT4si58E2D0/preview">here</a>. The **event schedule** with time blocks following **National-level conflicts** can be found <a target="_blank" href="https://docs.google.com/spreadsheets/d/1t9wu2wkN_lzYU5jImofAwnHHkH3B0ZJaH22wavbKG3Y/edit?usp=sharing">here</a>. This year, we will use **State-level** rules for all events.

As always, please feel free to reach out with any questions or concerns!
